Simulación de Movimientos Físicos

Este Sitio Web esta diseñado con el propósito de poder observar dos movimientos fisicos: el Movimiento Rectilíneo Uniforme Acelerado y el Movimiento Parabólico. Se podrán configurar los datos de dos objetos, el Proyectil representando el movimiento parabólico, y el Objetivo repesentando el movimiento rectilíneo. Al iniciar la simulación se podra visualizar la trayectoria y, posteriormente, la colisión entre ambos objetos.
